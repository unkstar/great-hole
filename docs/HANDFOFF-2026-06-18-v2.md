### New commit (7039271) — 6 files changed, +191/-37

| Fix | Description |
|:---:|------|
| **BF1** | Timer wait only when `batch_queue->empty()`. Under load, encoder processes back-to-back without 4ms idle. |
| **BF2** | `RaptorQ::GenerateSymbol(esi, out_buf)` overload — reuse single `make_unique<uint8_t[]>(T)` per SendBatch instead of per-symbol new/delete. |
| **BF4** | `WriteBatch` rewritten: `co_await` each packet send, no fire-and-forget. Fixes silent drops when socket buffer full. |
| **BF5** | `BuildBlob` + decoder blob parser: explicit little-endian byte writes for count/len fields (replaces native-endian `memcpy`). |
| **BF6** | PING/FEEDBACK with `FecSharedState`. Encoder sends PINGs. Decoder sets `pending_feedback_echo` → encoder sends FEEDBACK → remote decoder calculates RTT EWMA. `EvictStaleSlot` uses `_Shared->rtt_ewma_us` for adaptive decode timeout. |

### Critical bug fix in LuaLib
`fec_shared_state_new()` must call `interface.Schedule()` to balance `lua_yield` in `safe_yield` wrapper. Without it, the Lua coroutine suspends forever → FiberException crash.
